# deck-screenshot

캡처 이미지 위에 도형을 올린다. 이미지 파일은 바꾸지 않는다.

## 1. 요소

| 요소 | 모양 | 색과 글자 |
|---|---|---|
| 이미지 테두리 | 각진 사각형 테두리 0.75pt | `#D9CEC0` |
| 번호 배지 | 지름 0.32인치 원, 흰색 테두리 1.5pt | 채움 `#BC4E10`, 흰색 숫자 12pt 굵게, 맑은 고딕 |
| 강조 상자 | 테두리 2pt, 채움 없음 | `#BC4E10`. 이미지 한 장에 하나까지 |
| 가림 사각형 | 테두리 없음, 투명도 0 | 채움 `#5E6265`. 안에 글자를 넣지 않음 |
| 캡션 | 이미지 아래 0.1인치 | 10~12pt, `#5E6265`, "번호. 설명" 형식 |

- 번호 배지는 가리키는 요소의 왼쪽 위 모서리에 원의 중심을 둔다. 배지가 가리키는 글자를 덮지 않게 한다.
- 가림 사각형은 가릴 영역보다 상하좌우 0.03인치 크게 만든다.
- 이미지와 그 위의 배지, 상자, 가림 사각형은 그룹으로 묶는다.

## 2. 여러 장 배치

| 캡처 수 | 배치 |
|---|---|
| 2장 | 가로 2칸 |
| 3장 | 가로 3칸, 또는 사이에 화살표를 둔 가로 흐름 |
| 4장 | 2 × 2 또는 가로 4칸. 원고 지시를 따른다 |

- 같은 장의 캡처는 높이를 같게 맞춘다. 비율은 유지한다.
- 캡처 사이 간격은 0.2인치로 통일한다.
- 본문 영역(세로 2.0~5.2인치, 가로 0.6~9.4인치)을 넘지 않는다.

## 3. 가릴 곳 찾기

1. 사용자가 가릴 것을 말하면 그것을 가린다.
2. 말하지 않으면 이미지에서 주소창, 사람 이름, 프로필 사진, 메일 주소, 채팅 메시지 본문, 사이트 경로를 찾아 가릴 후보로 알린다. 가리기 전에 확인을 받는다.
3. 이미지에서 위치를 정확히 찾지 못하면 대략 위치에 가림 사각형을 두고, 쪽 번호와 함께 위치를 확인해 달라고 알린다.

## 4. 알릴 것

가림 사각형은 이미지 위에 올린 도형이다. 원본 이미지는 파일 안에 그대로 남아 있어서, 슬라이드에서 도형을 옮기거나 pptx에서 이미지를 꺼내면 가린 부분이 보인다. 작업을 마치면 아래를 함께 알린다.

- 가림 사각형을 넣은 쪽 번호
- 덱을 공유하려면 가린 부분을 지운 이미지로 교체해야 한다는 것. PDF로 내보내도 원본 이미지가 PDF 안에 그대로 남는다
