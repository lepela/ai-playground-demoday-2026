# deck-from-script

원고 문서 한 개를 받아 그 원고의 슬라이드를 템플릿 장표로 만든다. 문구는 원고 그대로 넣는다. 말투 정리는 deck-tone, 꾸미기는 deck-decoration이 따로 한다.

## 1. 원고 형식

원고는 슬라이드마다 아래 형식의 절로 되어 있다.

```
## 슬라이드 2-2. 처음 목표는 Loop였다
- 템플릿: T02 본문형
- 제목: 처음 목표는 Loop였다
- 부제: 2026-07-10, 쓰기 경로를 확인한 결과
본문 (확인한 사실 3개, 번호 목록):
1. ...
하단 한 줄: ...
시각 요소: ...
발표자 노트:
> ...
```

| 원고 항목 | 넣는 곳 |
|---|---|
| 템플릿 | 복제할 장표 (2절) |
| 제목, 부제 | 장표의 제목 상자, 부제 상자 |
| 섹션 제목, 숫자, 이 섹션에서 다룰 내용 | 섹션 구분 장표의 같은 이름 상자 |
| 본문 아래의 목록, 표, 문장 | 본문 영역 (세로 2.0~5.2인치) |
| 하단 한 줄 | 본문 영역 맨 아래 한 줄 |
| 발표자 노트 아래 인용문 | 슬라이드 노트 칸. 인용 부호(>)는 뺀다 |

슬라이드에 넣지 않는 것:

- "본문 (…)" 같은 괄호 설명. 배치 지시일 뿐 문구가 아니다
- 시각 요소 줄. 꾸미기 단계에서 deck-decoration이 읽는다
- 확인 필요, 데모 대비, 캡처할 때 가리는 것 같은 제작 메모
- 슬라이드 절이 아닌 절 전체: 이 파트가 전하는 것, 근거 자료, 넣지 않는 것, 제작할 때 남길 것, 작업 순서, 전체 구성과 시간 배분, 템플릿 장표 쓰는 법

## 2. 템플릿 장표

| 원고의 템플릿 값 | 복제할 장표 | 남기는 요소 | 지우는 요소 |
|---|---|---|---|
| 1번 표지 | 1번 | 전부 | 없음 |
| T02 | 2번 발표자 소개 | 전부 | 없음 |
| T02 본문형 | 2번 발표자 소개 | 제목, 부제, 오른쪽 위 로고, 하단 바와 그 글자 | 사진 자리 사각형과 안내 문구, 발표자명, 소속, 담당 업무, 관련 경험 상자 |
| T02-A | 3번 목차 | 전부 | 없음 |
| T02-B | 4번 스폰서 | 전부 | 없음 |
| T11 | 5번 섹션 구분 | 전부 | 없음 |
| 6번 Q&A | 6번 | 전부 | 없음 |
| 7번 감사합니다 | 7번 | 전부 | 없음 |

- 원본 템플릿 장표 7장은 마지막에 지운다. 복제한 장표만 남긴다. 사용자가 원본을 남기라고 하면 남긴다.
- 하단 바의 `[세션명]`은 원고 머리의 "하단 바 세션명" 값으로 바꾼다.
- 오른쪽 아래 장표 코드(T02, T11 등)는 쪽 번호로 바꾼다.

## 3. 순서

1. 원고 머리에서 파트 번호와 하단 바 세션명을 읽는다.
2. 원고의 슬라이드 절을 위에서부터 차례로 만든다. 사용자가 범위를 정하면(예: 1-0부터 1-8까지) 그 범위만 만든다.
3. 새 슬라이드는 사용자가 지정한 위치 뒤에 넣는다. 지정이 없으면 덱의 맨 뒤, Q&A 장표 앞에 넣는다.
4. 본문이 본문 영역을 넘치면 글자 크기를 12pt 아래로 줄이지 않는다. 넘친 슬라이드 번호를 알린다.
5. 표는 원고의 행과 열을 그대로 만든다. 표 서식은 꾸미기 단계에서 정한다.
