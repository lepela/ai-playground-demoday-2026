# deck-changelog

덱 안에 작업 기록을 남긴다. 기록은 덱 맨 뒤의 숨긴 슬라이드 "작업 기록"에 표로 둔다. 파일을 따로 만들지 않는다.

## 1. 기록 슬라이드

- 덱 맨 뒤에 제목이 "작업 기록"인 슬라이드가 없으면 빈 레이아웃으로 만들고 숨긴 슬라이드로 설정한다.
- 숨기기를 할 수 없으면 맨 뒤에 두고, 사용자에게 슬라이드를 숨겨 달라고 알린다.
- 표의 열은 아래와 같다.

| 순번 | 날짜 | 주체 | 요청 또는 작업 | 스킬 | 바뀐 쪽 | 바뀐 내용 | 이유 |
|---|---|---|---|---|---|---|---|

- 주체는 Copilot 또는 사람이다.
- 표가 슬라이드를 넘치면 "작업 기록 (2)" 숨긴 슬라이드를 만들어 이어 쓴다.
- 글자 크기는 9pt, 글꼴은 맑은 고딕이다. 이 슬라이드는 발표에 쓰지 않으므로 꾸미지 않는다.

## 2. 기록하는 법

| 사용자가 한 말 | 기록 |
|---|---|
| "방금 한 거 기록해줘" | 이 대화에서 바로 앞의 Copilot 작업 한 건. 요청 문장은 사용자가 쓴 그대로 옮긴다. 바뀐 내용은 대표 문장 1~2개를 "전 → 후"로 적는다 |
| "사람이 고친 것: …" | 주체를 사람으로 두고 사용자가 말한 쪽, 내용, 이유를 그대로 적는다. 이유를 말하지 않았으면 비워 두고 묻는다 |
| "지금까지 한 거 기록해줘" | 이 대화에서 확인할 수 있는 Copilot 작업을 순서대로 모두 적는다. 이전 대화의 작업은 알 수 없으므로 적지 않는다 |

Copilot은 사람이 직접 고친 내용을 스스로 알 수 없다. 사람이 고친 것은 사용자가 말해 준 것만 기록한다.

## 3. 표 꺼내기

"사람이 고친 곳 표 만들어줘"라고 하면 기록에서 주체가 사람인 행만 골라 아래 표를 만든다. 발표용 슬라이드(예: 사람이 고친 곳 장)에 넣을 때는 사용자가 지정한 슬라이드에 넣는다.

| 슬라이드 | AI가 한 것 | 고친 것 | 이유 |
|---|---|---|---|

"요청 문장 목록 만들어줘"라고 하면 주체가 Copilot인 행의 요청 문장을 순번대로 나열한다.
