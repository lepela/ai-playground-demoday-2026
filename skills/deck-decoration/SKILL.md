# deck-decoration

이미 만들어진 슬라이드에 장식만 더한다. 슬라이드 구성과 문구는 빌트인 생성 기능이 만든 그대로 둔다.

## 1. 바꾸지 않는 것

- 테마 색, 슬라이드 마스터, 레이아웃
- 로고 위치와 크기, 하단 남색 바와 그 안의 문구, 오른쪽 아래 장표 코드
- 제목, 부제, 본문의 문구. 맞춤법 수정도 하지 않는다
- 표지(1번), Q&A, 감사합니다 장표의 이미지와 배치
- 발표자 노트

문구를 줄여야 글자가 들어가는 경우에는 고치지 않고, 어느 슬라이드인지 알려 준다.

## 2. 색

템플릿에서 쓰는 색만 쓴다. 강조색은 주황 하나이고, 한 슬라이드 안에서는 한 종류의 요소(숫자끼리, 단계 번호끼리 등)에만 쓴다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 남색 | `#08243F` | 제목, 표 머리 글자, 아이콘, 진행된 단계, 차트 기본 계열 |
| 주황 | `#BC4E10` | 섹션 숫자, 강조할 숫자, 경고, 막힌 곳 표시, 차트 강조 계열 1개 |
| 밝은 주황 | `#E77721` | Q&A·감사합니다 장표에만 |
| 본문 회색 | `#5E6265` | 부제, 보조 설명, 비교의 "이전" 쪽 글자 |
| 선 회색 | `#CBD6DF` | 표 구분선, 흐름 연결선, 차트 눈금선 |
| 카드 바탕 | `#F3EBDD` | 아이콘 원 바탕, 카드 바탕 |
| 카드 테두리 | `#D9CEC0` | 카드, 사진 자리 테두리 |
| 흰색 | `#FFFFFF` | 슬라이드 바탕 |

차트 계열이 셋 이상이면 테마 색 `#344557`, `#48776B`, `#EBA72D`, `#78573D`를 이 순서로 더한다.

## 3. 글자

- 글꼴은 맑은 고딕 하나다. 다른 글꼴을 넣지 않는다.
- 크기는 템플릿 값을 따른다.

| 요소 | 크기 | 굵기, 색 |
|---|---|---|
| 본문 장표 제목 | 30pt | 굵게, 남색 |
| 부제 | 16pt | 보통, 본문 회색 |
| 본문 | 14pt | 보통, 남색 또는 본문 회색 |
| 표 본문 | 13~14pt | 보통 |
| 캡션, 주석 | 10~12pt | 보통, 본문 회색 |
| 섹션 숫자 | 68pt | 굵게, 주황 |
| 큰 숫자 콜아웃 | 40~54pt | 굵게, 주황 또는 남색 |

- 본문은 왼쪽 정렬이다. 가운데 정렬은 큰 숫자 콜아웃과 표지 계열 장표에만 쓴다.
- 본문을 12pt 아래로 줄이지 않는다. 넘치면 1절의 방법으로 알린다.

## 4. 장식 패턴

원고에 "시각 요소:" 줄이 있으면 그 지시를 먼저 따른다. 없으면 본문 형태를 보고 아래에서 하나를 고른다. 한 슬라이드에 패턴은 하나다.

| 본문 형태 | 패턴 | 만드는 법 |
|---|---|---|
| 숫자 2~4개와 짧은 설명 | 큰 숫자 콜아웃 | 숫자를 40~54pt 주황 굵게, 아래에 12pt 회색 설명. 칸 사이 간격은 같게 |
| 순서가 있는 단계 3~5개 | 단계 흐름 | 둥근 사각형(카드 바탕, 카드 테두리)을 가로로 놓고 선 회색 화살표로 잇는다. 단계 번호는 주황 |
| "이전 / 이후", "문제 / 목표" 2열 | 비교 2단 | 왼쪽 열 글자는 본문 회색, 오른쪽 열 글자는 남색. 가운데 화살표 하나 |
| 날짜가 붙은 항목 3~5개 | 타임라인 | 가로 선(선 회색) 위에 주황 원, 원 위에 날짜, 아래에 두 줄 설명 |
| 원칙, 항목 3~4개 | 아이콘 목록 | 항목마다 지름 0.45인치 원(카드 바탕) 안에 남색 단색 아이콘 |
| 표 | 표 서식 | 머리 행은 남색 굵은 글자와 아래쪽 선 회색 선만. 세로선 없음. 줄무늬 바탕 없음 |
| 수치 비교 | 막대 차트 | 가로 막대. 기본 남색, 강조할 막대 하나만 주황. 값은 막대 끝에 표시. 범례는 계열이 둘 이상일 때만 |

아이콘은 PowerPoint의 기본 아이콘에서 고른다. 한 장표의 아이콘은 같은 스타일로 맞춘다.

## 5. 쓰지 않는 장식

- 제목 아래 강조선
- 카드 한쪽 모서리의 색 막대, 슬라이드 가장자리의 장식 띠 (템플릿에 원래 있는 하단 바와 Q&A 장표의 주황 세로 막대는 그대로 둔다)
- 그라데이션, 네온, 광택 효과, 3D 도형
- 진한 그림자. 그림자가 필요하면 투명도 80% 이상의 옅은 것 하나
- 이모지
- 장식용 스톡 사진. 원고가 요구한 캡처, 사진 자리만 둔다
- 애니메이션과 화면 전환 효과. 원고가 요구할 때만 넣는다

## 6. 배치

- 본문 영역은 세로 2.0~5.2인치, 가로 0.6~9.4인치다. 하단 바(5.35인치부터)와 로고를 침범하지 않는다.
- 요소 사이 간격은 0.3인치 또는 0.5인치 중 하나로 슬라이드마다 통일한다.
- 같은 종류의 슬라이드는 제목, 부제 위치가 같아야 한다. 장식 때문에 제목을 옮기지 않는다.
- 캡처 자리는 카드 테두리 색 사각형으로 두고 안에 "캡처: 무엇"을 12pt 회색으로 적는다.

## 7. 원고를 함께 받았을 때

- "발표자 노트:" 아래 인용문은 슬라이드 노트로 들어갔는지만 확인한다. 노트 문구는 고치지 않는다.
- "근거 자료", "넣지 않는 것", "이 파트가 전하는 것" 절의 내용은 슬라이드에 넣지 않는다.
- "템플릿: T11"은 섹션 구분 장표, "템플릿: T02 본문형"은 발표자 소개 장표의 제목, 부제, 하단 바를 쓴 본문 장표다.

## 8. 마친 뒤 확인

슬라이드마다 아래를 보고, 걸린 것만 목록으로 알린다.

1. 글자가 상자 밖으로 넘치거나 잘린 곳
2. 요소가 하단 바, 로고와 겹친 곳
3. 바탕과 글자의 대비가 낮은 곳 (밝은 바탕 위 선 회색 글자 등)
4. 한 슬라이드에서 주황을 서로 다른 종류의 요소에 쓴 곳
5. 같은 종류 슬라이드끼리 제목 위치가 다른 곳
6. 대괄호 입력란(`[발표자명]` 등)이 남은 곳
