# deck-final-check

덱 전체를 읽고 아래 항목을 확인한다. 서식(넘침, 겹침, 대비)은 deck-decoration의 점검이 맡으므로 여기서는 보지 않는다. 숨긴 슬라이드는 점검에서 뺀다.

## 1. 점검 항목

| 번호 | 항목 | 걸리는 경우 |
|---|---|---|
| 1 | 대괄호 입력란 | `[발표자명]`, `[직무]`, `[캡처]`, `[제작 후 채움]`처럼 대괄호로 감싼 안내 문구가 슬라이드나 노트에 남음 |
| 2 | 템플릿 장표 코드 | 오른쪽 아래에 T02, T02-A, T02-B, T11 같은 코드가 남음. 쪽 번호여야 함 |
| 3 | 하단 바 | `[세션명]`이 남았거나, 장마다 하단 바 문구가 다름 |
| 4 | 숫자 일치 | 같은 대상을 가리키는 숫자가 장마다 다름 (예: 한 장에는 80건, 다른 장에는 79건). 날짜, 건수, 비율, 시간, 파일 크기를 모아 비교 |
| 5 | 목차 | 목차 장의 항목 이름과 섹션 구분 장표의 제목이 다르거나, 순서가 다름 |
| 6 | 섹션 번호 | 섹션 구분 장표의 숫자가 01, 02, 03 순서가 아님 |
| 7 | 원본 템플릿 장표 | 템플릿 원본 장(빈 표지, 대괄호만 있는 소개 장 등)이 복제본과 함께 남음 |
| 8 | 스폰서 장 | 스폰서 장이 대괄호 상태로 남음. 넣을지 지울지 발표자에게 확인 |
| 9 | 빈 노트 | 표지와 섹션 구분 장표를 뺀 장에 발표자 노트가 없음 |
| 10 | 행사 정보 | 행사 이름, 날짜, 세션 제목이 장마다 다르게 적힘 |

## 2. 보고

| 번호 | 쪽 | 찾은 내용 | 확인할 것 |
|---|---|---|---|

- 항목마다 걸린 것이 없으면 그 항목 번호와 "통과"를 한 줄로 적는다.
- 4번 숫자 일치는 값이 다른 쪽 번호를 모두 적는다. 어느 쪽이 맞는지는 판단하지 않는다.
- 마지막 줄에 걸린 항목 수를 적는다.
